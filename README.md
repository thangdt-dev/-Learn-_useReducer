# Learn useReducer
This project is a simple Todo App built with React to practice and understand the `useReducer` hook. It demonstrates how to manage complex state logic in a more predictable and scalable way compared to `useState`.

The app allows users to add, delete, and toggle tasks, with all state transitions handled through a reducer function. This project focuses on core concepts such as actions, reducers, and immutable state updates, making it a practical example for learning state management in React.

Technologies used: React (Hooks), JavaScript (ES6+), and basic CSS.

This repository is intended for learning purposes and serves as a foundation for building more advanced applications using `useReducer`.
